**Unfortuantly, I'm not sure how I would even distribute my mod's sources.**

Due to [the Minecraft EULA](https://www.minecraft.net/en-us/eula), even the mods themselves cannot contain Minecraft source. How do modders get around this? By only publishing their changes!

However, because this mod does not use a loader, it directly modifies Minecraft source. Instead, this GitHub repo's purpose is to provide a hub for issue reporting, suggestions, etc!

---

There is one way to view the sources, though.

If you extract the mod's ZIP and decompile+deobfuscate the classes, you can view the sources! While I can't guarantee you'll actually *find* my modifications, you can probably guess where everything goes.
